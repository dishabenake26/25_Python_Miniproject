# Escape Room: The Mystery Game 🎮

## 📌 About the Project

**Escape Room: The Mystery Game** is an interactive 2D puzzle-adventure game developed using Python and Pygame. Players explore mysterious environments, discover hidden clues, solve puzzles, and complete challenges to progress through four unique levels.

The project was created to explore creative game development and apply Python programming concepts in a practical application.

## 🎯 Game Levels

### Level 1 — The Forgotten Room

Explore an old, mysterious room, discover hidden numerical clues, unlock a cupboard, and find the key to escape.

### Level 2 — The Lost Energy Core

Explore a mysterious environment, solve challenges, and uncover the secrets of the lost energy core.

### Level 3 — The Maze of Shadows

Navigate through dark, winding passages, overcome obstacles, and find the correct path to the exit.

### Level 4 — The Cursed Altar

Face the final mystery, solve the last challenge, and complete the escape adventure.

## ✨ Features

- Four unique levels with different themes and challenges.
- Interactive game environment and objects.
- Hidden clues and puzzle-solving challenges.
- Countdown timer for added difficulty.
- Graphical user interface with menus and controls.
- Sound effects and animations.
- Score tracking and level progression, where implemented.

## ⚙️ Installation and Setup

**Step 1: Install Python**

Download Python from [python.org](https://www.python.org/downloads/).

**Step 2: Install Pygame**

Open the terminal and run:

```bash
pip install pygame
```

**Step 3: Open the Project**

Open the project folder in Visual Studio Code.

**Step 4: Run the Game**

Run the main Python file. For example, if your main file is named `main.py`:

```bash
python main.py
```

## 🎮 How to Play

1. Launch the game and open the main menu.
2. Start the game and select an available level.
3. Explore the environment and interact with objects.
4. Find clues and solve puzzles to complete the objectives.
5. Progress through the levels and complete the final challenge.
